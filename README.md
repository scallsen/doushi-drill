# A tool to practice conjugating Japanese grammar forms.

## Key features
### Conjugate your way
Choose any combination of word types, states, and forms. 
### Type or flip
Manually type your response for automatic grading, or manually flip cards to grade yourself faster.
### Set word diffuculty
Choose Beginner friendly words up to Intermediate, based on your current level.

## Features
- Supports verbs, adjectives, and nouns
- Set states: past/present, polite/plain, positive/negative)
- Drill specific verb forms: te form, potential, conditional, volitional, passive, causitive, passive-causative, imperative
- Typing input with automatic grading, or manually click/keyboard to flip cards and mark answer yourself
- Build up and track your best streak
- Choose words based on difficulty (Beginner > Upper beginner > Intermediate)
- TTS audio playback (locally powered by your browser or OS)
- Japanese vocabulary with english meanings sourced from [JMdict](https://www.edrdg.org/~smg/)
- Enhanced mobile input experience
